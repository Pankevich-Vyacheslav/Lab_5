# Висновок:

Під час виконання лабораторної роботи було досліджено, реалізовано та протестовано алгоритми Прима (Prim) і Крускала (Kruskal) для побудови мінімального кістякового дерева зваженого неорієнтованого графа. Для графа варіанта №15, що містить 8 вершин і 14 ребер, було побудовано матрицю суміжності з вагами та списки суміжності.

Шляхом ручного трасування та графічної візуалізації досліджено послідовність побудови мінімального кістякового дерева за обома алгоритмами. Також було розроблено та протестовано їхні програмні реалізації мовою Python. Результати програмного виконання повністю збіглися з результатами ручної побудови: в обох випадках отримано мінімальне кістякове дерево із 7 ребер та загальною вагою 17.

Порівняльний аналіз показав, що алгоритм Прима поступово розширює дерево від початкової вершини, тоді як алгоритм Крускала послідовно розглядає ребра за зростанням їхніх ваг, уникаючи утворення циклів. Незважаючи на відмінності у принципах роботи та послідовності вибору ребер, обидва алгоритми сформували однакове мінімальне кістякове дерево.
Таким чином, було набуто практичних навичок представлення графів, побудови мінімальних кістякових дерев, трасування алгоритмів та перевірки правильності отриманих результатів за допомогою програмного моделювання.
